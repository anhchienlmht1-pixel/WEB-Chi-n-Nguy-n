# UX profile — C Stock

Aesthetic: editorial (paper / ink / black band), data-dense product pages.
Product chrome (header, panels, tables, stock pages) follows the `motion` skill
tables: 100/150/200/300ms, ease-out in, ease-in out, `transform` + `opacity` only.

## Notes

- **Marketing exception — home hero intro only** (`client/src/components/HomeHero.tsx`,
  `.hero-*` in `client/src/index.css`): the one-time entrance may use longer
  durations (up to ~1.9s for the trend-line reveal, 450–1000ms for the rest),
  staggered delays, and a small damped shake (≤4px) when the bull lands.
  It may also animate paint-only properties (`clip-path` for the line reveal,
  `color` for the letter scan). Still banned: layout properties
  (width/height/top/left/margin/padding), bounce/elastic/overshoot easing,
  and any infinite loop.
- Under `prefers-reduced-motion: reduce` the hero is a plain 150ms fade — no
  movement, no reveal, no shake.
- Everything outside the hero stays on the token scale.
